## The flocking demo

The first screen runs a live port of the boids flock from my Game AI coursework (Project 1). I wrote the original in C++ on DigiPen's CS380 AI framework, which renders with DirectX 11.

**What was ported.** My steering functions (`Seek`, `Separation`, `Alignment`, `Cohesion` and `Containment` from `Steering.cpp`), the neighbour search from my `L_Flock` behaviour-tree node, and my `move_flock()` and `truncate()` code.

**Kept the same as the original:**

- The steering formulas.
- Weights: separation 0.5, alignment 0.25, cohesion 0.25, containment 1.0.
- Perception radius √1000 (about 31.6), separation radius 10 and max speed 30.
- Max force 2000, used as a squared length.
- Containment settings: look-ahead of 3 frames (`dt × 3`), buffer 10, strength 30.
- A 100 × 100 world with 36 birds spawned in a 6 × 6 grid.
- Birds update one after another within each frame, as the framework's agents did.

**Differences from the original:**

- **2D instead of 3D.** The original pins every bird to `y = 110`, so the port runs on the XZ plane and draws it from above.
- **Three bugs fixed:**
  - Every bird now sees the whole flock. In the original, each bird only saw the birds spawned before it.
  - Each bird starts with its own random heading. In the original, every bird started with the same velocity.
  - Normalizing a zero vector returns zero instead of NaN, matching DirectX.
- **One quirk kept on purpose.** `truncate()` scales an over-limit vector by `maxLength² / length²` instead of its square root, so the vector comes out shorter than the limit. The flock was tuned with this behaviour, so it stays. The *Exact truncate* option in the tuning panel switches to the corrected maths.

  You can see a side effect in the demo: a bird that overshoots the edge of the map sometimes drifts outside for a while. The further out it goes, the harder containment pushes and the more `truncate()` shrinks that push. An arrow at the edge of the viewport points to any bird that is out of view.
- **Frame time.** The port uses the browser's frame time in seconds, capped at 1/20 s so that a slow frame or a background tab can't fling the birds.
- **Web-only additions.** Debug views for neighbours, steering forces and the containment zone; sliders for the weights, perception radius and speed; and click-to-inspect for any bird.

**Not included:** DigiPen's framework code (agents, the behaviour-tree system, terrain and rendering). The port re-implements only what my code needed from it, and the original C++ is not in this repo.

## Running it locally

Open `index.html` in a browser. To serve it instead, run:

```
python -m http.server
```

Then visit http://localhost:8000. The fonts and the YouTube embed need an internet connection.

## AI usage

I used AI to build this site. This section explains which parts.

**Made with AI (Claude, by Anthropic):**

- **The site's design and front-end code.** This covers the layout, styling and colour palette, the loading screen, the slide-in page transitions, the name glitch effect and the project selector. The first version of the site, including its wording, was generated by AI from my résumé in an earlier conversation. I then developed it further with AI: I chose the direction (a game-style site, slide-in screens, the green and cyan palette), and tested the results and asked for fixes.
- **The JavaScript port of my flocking code.** AI translated my C++ into JavaScript, following a porting brief I wrote. The brief lists the constants, which quirks to keep or fix, and which framework code not to copy. AI also wrote the demo's drawing code, debug views and controls.
- **This README.** AI drafted it and I edited it.

**My own work:**

- The original C++ flocking code that the demo is ported from, including the steering functions, the weights and the tuning.
- The projects, experience and education described on the site, and the facts about them.
- Deciding what to build, and reviewing and testing the result.

**How the AI-written code was checked:**

- The port was compared line by line with the original C++ for formulas and constants.
- It was run outside the browser for a simulated 60 seconds in both truncate modes, to confirm there were no NaN values and that speeds stayed within the limit.
- The site was tested at desktop and phone sizes, with reduced motion turned on, and inside a sandboxed preview frame.
